# De Mayo Bible Studies — Platform V2 Roadmap

## Purpose
Build a professional, free, bilingual Christian ministry platform while keeping the public production application stable. All new work is developed and tested in `de-mayo-bible-study-dev` before release.

## Delivery rules
- Develop in focused feature branches.
- Keep `main` deployable.
- Use pull requests and automated checks.
- Preserve local user data and offline support.
- Do not expose API keys in GitHub Pages.
- Test iPhone, Android, Mac, and Windows before production release.
