# Contributing

This is the private working process for De Mayo Bible Studies development.

1. Record the bug or enhancement in GitHub Issues.
2. Make one focused change at a time.
3. Update `CHANGELOG.md`.
4. Test the affected feature on desktop and mobile.
5. Commit with a clear message, such as `Fix reading plan duplicate titles`.
6. Promote tested changes to the production repository only after approval.

Never place passwords, API secrets, private keys or personal user data in this repository.
